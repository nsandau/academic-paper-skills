# Prose-check mode

Diagnose language only where it affects clarity, precision, or scholarly tone.

Look for:
- Vague stock vocabulary
- Throat-clearing openers
- Redundant metadiscourse
- Overloaded sentences
- Paragraphs containing several unrelated claims
- Ambiguous pronouns
- Excessive nominalization
- Unnecessary passive voice, while preserving it where agent identity is irrelevant
- Unsupported intensifiers such as clearly, obviously, dramatically, or crucially
- Excessive hedging that obscures the actual claim
- Insufficient hedging for uncertain evidence
- Repetition of the same claim across sections
- Terminology drift
- Transitions that announce rather than explain logic

Do not optimize for an AI detector. Optimize for readable, precise academic prose.
