# Rebuttal mode

Draft a point-by-point response only after the reviewer comments and intended manuscript changes are known.

For each comment:
- Acknowledge the concern without empty flattery.
- State the author's interpretation of the issue.
- Explain the response.
- Describe the exact change made.
- Give the manuscript location.
- If disagreeing, explain why with evidence and, where useful, clarify the manuscript to prevent the misunderstanding from recurring.

Never claim a revision has been made unless it appears in the supplied revised manuscript or the user explicitly states it will be made.
