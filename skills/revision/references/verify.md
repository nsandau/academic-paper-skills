# Revision verification mode

Inputs:
- Original reviewer comments
- Response letter
- Revised manuscript
- Optional original manuscript

For every reviewer concern:
1. Extract what the response promises.
2. Locate the claimed manuscript change.
3. Determine whether it exists.
4. Determine whether it substantively addresses the concern.
5. Check whether the change creates contradictions elsewhere.

Statuses:
- resolved
- partly resolved
- unresolved
- response-manuscript mismatch
- new inconsistency introduced

Do not infer resolution solely from the response letter.
