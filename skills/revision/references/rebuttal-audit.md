# Rebuttal-audit mode

Requires both reviewer comments and an existing response draft.

For each atomic reviewer concern classify:
- addressed
- partially addressed
- missing
- misread
- response claims a change not found in manuscript
- manuscript change not mentioned in response
- unsupported disagreement
- tone risk

Check that multipart comments receive multipart answers. Do not generate an entirely new rebuttal unless the user separately asks for rewriting after the audit.

## Output
A per-comment coverage table, gap list, evidence risks, tone risks, and targeted improvements.
