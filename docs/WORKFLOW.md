# Suggested workflow

This is a convenience sequence, not a pipeline contract. Every skill can be used independently.

## 1. Conceive
`socratic-research` -> `research-question` -> `research-design`

Use `research-brief` when you need a bounded preliminary answer before committing to a deeper investigation.

## 2. Build evidence
`literature-search` -> `source-evaluator` -> `literature-synthesis` -> `research-gap`

Use `fact-check` at any point for externally verifiable claims.
Use `claim-evidence-audit` when you want to know whether citations and data actually support manuscript wording.
Use `evidence-synthesis` for systematic reviews, risk-of-bias assessment, meta-analysis, or certainty grading.
Use `literature-monitoring` after an evidence base already exists and you need to identify consequential developments since a cutoff date.

## 3. Plan the paper
`paper-planner` -> `argument-builder` -> `paper-outline`

You can change the order of argument-builder and paper-outline depending on how you think.

## 4. Write
Use `style-calibration` when you want later drafting to reflect your established academic voice.
Use `section-writer` for section drafting.
Use `academic-writing` for introduction, discussion, abstract, title, keywords, and prose diagnostics.
Use `figure-table-planner` for visual communication.

## 5. Challenge
Use `argument-stress-test` before peer review.
Use `methodology-review` for a dedicated methods pass.
Use `peer-review` for independent review lenses, quick triage, guided review, or bounded calibration.
Use `journal-fit` for a named target venue.
Use `review-synthesis` when several people or reviewer passes have commented.

## 6. Verify
Use `citation-audit` for references, metadata, version families, and cross-index checks.
Use `claim-evidence-audit` for citation-to-claim support.
Use `manuscript-integrity-audit` for whole-paper numerical, cross-section, temporal, originality, and inference consistency.
Use `reporting-guidelines` to audit applicable reporting checklists.

## 7. Revise and submit
Use `revision` in coach, rebuttal, rebuttal-audit, or verify mode. Scoped edits and claim-drift checks should be active for substantive revision.
Use `submission-check` for venue preflight.
Use `ai-disclosure` if a venue or policy requires an AI-use statement.
